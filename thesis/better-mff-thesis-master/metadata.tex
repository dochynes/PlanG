\def\AbstractEN{%
{
This thesis presents PlanG, a library that provides access to the non-isomorphic
graph generators \texttt{geng} and \texttt{plantri} for general and planar
graphs through a unified C++ interface. It addresses the challenge of
integrating their low-level C APIs and internal data structures with
modern C++ code. The library offers type-safe configuration,
callbacks for pruning, filtering, and result processing, as well as
views over internal data without unnecessary copying. Both backends
support selected concepts of the Boost Graph Library. In addition,
the \texttt{geng} generator has been extended with canonical graph
generation using vertex color classes and rooted vertices. Performance
evaluation shows that PlanG achieves performance comparable to the original
generators during pure graph generation while introducing only a small overhead
for the callback layer. Library therefore facilitates experimental graph exploration,
algorithm testing, and the search for counterexamples.


}

\def\AbstractCS{%
{
Tato práce představuje knihovnu PlanG, která zpřístupňuje
generátory neizomorfních obecných a rovinných grafů \texttt{geng} 
a \texttt{plantri} prostřednictvím jednotného rozhraní v C++. Řeší 
tím obtížné propojení jejich nízkoúrovňových C rozhraní a interních 
datových struktur s moderním C++ kódem. Knihovna poskytuje typově bezpečnou 
konfiguraci, callbacky pro prořezávání, filtrování a zpracování výsledků a 
views nad interními daty bez zbytečného kopírování. Oba backendy podporují 
vybrané koncepty Boost Graph Library. Generátor \texttt{geng} byl navíc 
rozšířen o kanonické generování grafů s barevnými třídami a zakotvenými 
vrcholy. Měření ukazují srovnatelný výkon s původními generátory při čistém 
generování a malou režii callbackové vrstvy. Knihovna tak usnadňuje experimentální 
zkoumání grafů, testování algoritmů a hledání protipříkladů.
    
}
